# 管理者短视与企业绿色创新——基于年报MD&A文本测度的实证研究

> 毕业论文模拟稿 · NLP 文本测度构建方法应用 · 零依赖可复现

## 研究简介

本研究将**学到的 NLP 文本测度构建方法**应用于企业绿色创新场景：以年报"管理层讨论与分析"（MD&A）为语料，构建**管理者短视**文本测度指标，并检验其对企业**绿色创新**的影响。

- **核心发现**：管理者短视与企业绿色创新显著负相关（β = −0.152，p < 0.01）
- **研究方法**：种子词集确定 → Word2Vec 语义扩充 → 词频标准化三步法
- **样本**：2018—2023 年沪深 A 股上市公司，3,247 家公司、14,586 个观测

## 研究步骤（完整清晰合理）

1. **问题形式化**：管理者短视的认知特征无法从财务报表直接读取，NLP 文本测度提供新出路
2. **文献综述与 Gap**：短视经济后果研究未覆盖非财务战略行为；绿色创新驱动研究对管理层认知刻画粗糙
3. **理论假设**：短视损失厌恶 + 委托代理 → H1 短视抑制绿色创新
4. **测度构建（方法学核心）**：
   - 语料获取（MD&A 章节，巨潮资讯网批量下载）
   - 文本预处理（PDF 提取 + jieba 分词 + 财经停用词）
   - 三步法：10 个种子词 → Word2Vec 扩充至 28 词 → 词频/总词频×100
5. **实证分析**：描述性统计 → 信效度检验 → 基准回归 → 稳健性检验 → 机制分析 → 异质性分析
6. **结论与展望**：核心发现 + 政策启示 + 局限

## 复现方法

代码零第三方依赖，任意装有 Python 3 的机器可直接运行：

```bash
cd code
python myopia_metric.py
```

运行后将输出：
- 种子词集（10 个）与扩充后最终词集（28 个）
- 4 家样本公司的短视指标（Myopia）实测值
- 信效度检验（Pearson r = −0.954，短视越高研发投入越低）
- 异质性分析（非国企 vs 国企）
- 结果持久化到 `code/data/myopia_result.json`

## 测度方法学要点

本文借鉴胡楠等（2021）《管理世界》的方法，核心是将"管理者短视"这一不可直接观测的认知特征，通过年报 MD&A 中**短期视域词汇**的出现频率转化为可计算的连续型测度。词集构建采用"种子词 + Word2Vec 语义扩充"保证覆盖面，统计采用"词频/总词频×100"标准化保证可比性，是 NLP 测度构建中典型的"词典法 + 表示学习"混合范式。
