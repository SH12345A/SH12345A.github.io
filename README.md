# 面向电商智能客服的中文问句语义相似度度量构建与实证研究

> 毕业论文模拟稿 | 研究方向：自然语言处理与度量构建 | 作者：沈鹤（大数据管理与应用）

## 一、研究概述

本文以"度量构建方法"为主线，面向电商智能客服的中文问句匹配问题，构建了**多层级融合语义相似度度量框架**。

- **字面层**：Jaccard（字符 bigram）、归一化编辑距离、TF-IDF 余弦（字符 3-gram）
- **语义层**：基于点互信息 PPMI 的自构建分布词向量余弦（零预训练依赖，纯 Python 可复现）
- **融合层**：数据驱动权重学习（验证集网格搜索）

**核心发现**：字面度量在电商短问句场景下 AUC < 0.5（出现"反向"现象）；PPMI 语义度量是唯一 AUC > 0.5 的单度量（0.538）；融合度量取得最优 F1（0.882）与 AP（0.832）。

## 五、关键技术点

| 度量 | 公式核心 | 适用性 |
|---|---|---|
| Jaccard | \|G(a)∩G(b)\| / \|G(a)∪G(b)\| | 字面重叠，对词序不敏感 |
| 编辑距离相似度 | 1 − Lev(a,b)/max(\|a\|,\|b\|) | 纠错别字 |
| TF-IDF 余弦 | cos(v(a),v(b)) | 关键词匹配，降低高频噪声 |
| PPMI 词向量余弦 | cos(Σe(w)/\|q\|) | 跨字面差异识别近义 |
| 融合度量 | Σwᵢmᵢ/Σwᵢ | 多层互补，权重数据驱动 |
