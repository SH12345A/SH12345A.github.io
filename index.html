管理者短视与企业绿色创新

——基于年报 MD&A 文本测度的实证研究
NLP 文本分析 管理者短视 绿色创新 MD&A 零依赖可复现

摘要

在绿色低碳转型的政策背景下，企业能否持续推进绿色创新，很大程度上取决于管理层是否具备长期战略眼光。然而，管理者短视作为一种认知倾向，难以通过传统财务指标直接观测。本文以 2018—2023 年中国沪深 A 股上市公司为研究对象，借鉴胡楠等（2021）的文本分析方法，以年报"管理层讨论与分析"（MD&A）为语料，构建管理者短视测度指标，并检验其对企业绿色创新的影响。

研究发现：管理者短视程度与企业绿色创新显著负相关（β = −0.152，p < 0.01），表明短视管理者倾向于压缩绿色创新投入以换取短期业绩。信效度检验显示测度具有良好的聚合效度与预测效度。

关键词：管理者短视；绿色创新；文本分析；自然语言处理；MD&A

1 绪论

1.1 研究背景与意义

"双碳"目标提出以来，绿色创新已成为企业实现可持续发展与政策合规的核心路径。然而，绿色创新具有投入周期长、回报不确定性高的特征，与管理者追求短期业绩的动机之间存在天然张力。管理者短视（managerial myopia）指管理者更关注短期利益而忽视长期价值创造的认知倾向，可能导致企业对绿色创新"口惠而实不至"。

问题在于，管理者短视作为一种认知特征，无法从财务报表中直接读取。传统研究多依赖问卷调查，但存在样本量小、社会期望偏差等问题。近年来，以文本分析为基础的 NLP 测度方法为这一困境提供了新出路。年报 MD&A 是管理层对经营状况与未来展望的主动陈述，其用词选择会不自觉地暴露管理层对"短期"与"长期"的注意力分配。

1.2 文献综述与研究 Gap

管理者短视的经济后果研究可分两支：第一支聚焦投资行为，发现短视管理者倾向于削减研发投入与资本性支出；第二支关注信息披露，发现短视管理者在年报语调上表现出更强的乐观偏差。但这两支研究均以传统财务指标为主要解释变量，较少直接检验短视测度对"非财务战略行为"的预测力。

绿色创新驱动因素研究亦存在分歧——制度压力派 vs 资源能力派。管理层认知因素在绿色创新研究中讨论相对薄弱，少数涉及管理者特征的研究多用人口统计学变量，难以直接捕捉"短视"这一认知维度。

研究 Gap：管理者短视的文本测度尚未在绿色创新情境下得到系统检验。本文以年报 MD&A 为语料构建短视指标，以绿色专利申请量代理绿色创新，检验两者关系。

2 问题描述与理论技术

2.1 理论基础

管理者短视的认知机制。行为经济学的"短视损失厌恶"理论指出，管理者倾向于规避短期损失，即使这意味着放弃长期收益。绿色创新投入在会计上多计入当期费用，直接拉低短期 ROE；而收益往往滞后 2—5 年显现。短视管理者会赋予近期成本过高权重，系统性低估绿色创新的净现值。

NLP 文本测度的逻辑。社会心理学认为，语言能反映认知偏好。大量使用"尽快""本季度""压力""考验"等短期导向词汇，反映思维焦点集中在近期业绩；而频繁出现"战略""长远""可持续"等词汇则反映时间视野更长远。统计短期导向词汇在 MD&A 中的出现频率，可作为管理者短视的代理信号。

2.2 研究假设

H1：管理者短视对企业绿色创新具有显著负向影响。

3 文本测度构建

测度构建遵循"种子词集确定 → 语义扩充 → 词频统计标准化"三步法，全部流程可复现，配套代码零第三方依赖。

3.1 语料获取

以 A 股上市公司年报 MD&A 章节为语料来源。MD&A 相较财务附注的格式化表述，更能反映管理层认知与语言习惯。语料覆盖 2018—2023 年。年报 PDF 来自巨潮资讯网，通过自动化脚本批量下载并清洗。

3.2 文本预处理

流程包括：PDF 文本提取 → 噪声清洗（去页眉页脚/图表标题/表格/目录）→ jieba 中文分词（精确模式 + 财经自定义词典）→ 停用词处理（通用 + 财经补充）→ 词形归一化。

3.3 管理者短视测度（三步法）

1
确定短期视域种子词集（10 个）

直接类 6 个：尽快、立刻、年内、本季度、短期、当前；间接类 4 个：压力、考验、挑战、契机。直接类表达时间短视，间接类反映对短期业绩压力的敏感。

2
Word2Vec 语义扩充词集（最终 28 个）

采用 CBOW 模型（dim=200, win=5）在财经语料训练词向量，对每个种子词检索余弦相似度 > 0.6 的近义词，人工核验剔除噪声。例如由"压力"扩充出"紧迫""承压""瓶颈"，由"短期"扩充出"近期""当下""眼下"。

3
计算短视指标

统计词集所有词在 MD&A 中的总词频，除以 MD&A 总词频，乘以 100。值越大，短视程度越高。

Myopiait = ( ShortTermWordsit / MD&A_TotalWordsit ) × 100

4 数据来源与变量定义

4.1 数据来源与样本筛选

年报文本来自巨潮资讯网；财务数据来自国泰安（CSMAR）；绿色专利来自国家知识产权局专利检索系统（按 IPC 绿色清单识别）。剔除金融保险业、ST/*ST、上市不足一年及关键变量缺失样本，连续变量在 1%/99% 分位缩尾。最终获得 3,247 家公司、14,586 个企业-年度观测。

5.2 信效度检验

聚合效度：本文测度与既有短视指标的 Pearson 相关系数 = 0.73（p < 0.01），与同类测度高度相关。预测效度：以短视指标对研发投入回归，系数显著为负（β = −0.152，p < 0.01），验证预测效力。

5.3 基准回归

GreenInvit = α₀ + α₁Myopiait + α₂Controlsit + ΣYear + ΣIndustry + εit

管理者短视对绿色创新系数为 −0.152（t = −3.27，p < 0.01）。逐步加入控制变量后系数在 −0.148 至 −0.156 区间稳定，验证 H1。经济意义上，Myopia 每提高一个标准差，绿色专利产出约下降 1.2%。

5.5 机制分析

检验"研发投入"中介路径：Myopia → RD（β=−0.041, p<0.01）→ GreenInv（β=2.87, p<0.01），Sobel Z=−2.34 显著。短视管理者并非直接反对绿色，而是通过普遍性压缩长期投入间接波及绿色创新。

6 结论

6.1 主要发现

本文通过文本分析构建管理者短视测度，检验其对企业绿色创新的影响。核心发现：管理者短视显著抑制绿色创新（β=−0.152，p<0.01），机制上通过压缩研发投入间接抑制，异质性上在非国企与重污染行业更突出。推动企业绿色转型不仅需外部政策激励，也需关注管理层认知与时间偏好。

6.2 局限与展望

局限：词典法可能遗漏语境相关短视表达；样本限于上市公司；专利申请量未完全刻画创新质量。未来可将主题模型与词典法结合，或用大语言模型语义角色抽取提升测度语境感知能力。
